RELEASE_TYPE: patch

This patch improves the display of functions generated by
:func:`~hypothesis.strategies.functions`.  If the ``returns=`` strategy can
only produce a single value, the function is now shown as a constant lambda
such as ``f=lambda x: 3``, instead of noting each call to it separately.

We also respect the ``_repr_pretty_()`` method of objects which define one in
a few more places, such as the arguments of a failing example.
