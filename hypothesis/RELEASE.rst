RELEASE_TYPE: patch

This release extends a recent shrinking improvement to strategies which
``.map(...)`` a string-building function.  When the mapped function builds
its output from constant pieces - by concatenation, f-strings,
:meth:`str.format` or %-templates, ``str()``, or string methods like
``.upper()``, ``.replace()``, ``.zfill()`` and ``sep.join(...)``, including
chains of these - values it produced can now be re-encoded and shrunk as if
generated by a wider branch of a union, as in
``st.text() | st.sampled_from([...]).map(lambda s: "id-" + s)``.
