RELEASE_TYPE: patch

This patch makes the ``random.Random`` instances generated by
:func:`~hypothesis.strategies.randoms` match the error behavior of real
:class:`random.Random` objects for invalid arguments: ``randint``,
``randrange``, ``getrandbits``, ``randbytes``, ``binomialvariate``,
``choice``, ``choices``, and ``_randbelow`` now raise the same
``ValueError``, ``IndexError``, or ``TypeError`` as the standard library,
instead of silently returning out-of-range values or failing later inside
the Hypothesis engine with a confusing ``ValueError`` from an internal
``randint`` call.

Internally, ``ConjectureData.draw_integer`` now validates that
``min_value <= max_value`` and raises ``InvalidArgument`` immediately,
rather than recording an impossible constraint which could crash the
engine during novel-prefix generation.
